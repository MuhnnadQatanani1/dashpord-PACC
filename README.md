# المرصد الوطني لمؤشرات الفساد - هيئة مكافحة الفساد الفلسطينية

منصة وطنية فلسطينية تفاعلية لرصد وتحليل ونشر مؤشرات النزاهة والشفافية ومكافحة الفساد، مبنية بالاعتماد على البيانات الإحصائية الرسمية. تستهدف المواطنين والباحثين والإعلاميين وصناع القرار، وتوفر لوحات بيانات تفاعلية وخريطة جغرافية ومؤشرات وتقارير.

> National Corruption Indicators Observatory — Palestinian Anti-Corruption Commission

## المميزات الرئيسية

- **ثنائي اللغة بالكامل (عربي / English)**: نظام i18n موحّد عبر `src/i18n/` يشمل واجهة الاستخدام (`t()`)، وبيانات المحتوى (`d()`)، والاتجاه RTL/LTR، وتنسيق الأرقام حسب اللغة (ar-EG / en-US).
- **لوحة بيانات تفاعلية** (`/dashboard`): بطاقات KPIs ورسوم بيانية (خطي/أعمدة/دائري/دونات) عبر Recharts لكتالوج المؤشرات.
- **خريطة فلسطين التفاعلية** (`/map`): خريطة Leaflet تفاعلية للمحافظات تعرض الشكاوى والبلاغات، مع بيانات قطاع غزة 2024.
- **المؤشرات الرئيسية** (`/main-indicators`): 29 مؤشراً رئيسياً مع مصفوفة جهود إنفاذ القانون، قابلة للطباعة والتصدير إلى Excel.
- **قسم التقارير** (`/reports`): مكتبة تقارير (سنوية، متخصصة، استطلاعات رأي، إضاءات دولية) مع صفحة إدارة تعتمد على Supabase.
- **قصص البيانات** (`/stories`) و **رحلة المرصد** (`/journey`) ومكونات توضيحية تفاعلية.
- **نظام قراءة صوتية (TTS)**: قراءة محتوى الصفحة صوتياً مع تحسين اختيار الأصوات العربية الطبيعية.
- **أداة وصول (Accessibility Widget)**: تحسينات لضعاف البصر وتفضيلات القراءة.
- **تصميم متجاوب** احترافي بألوان حكومية (كحلي داكن + أخضر)، يعمل على الجوال والحاسوب.

## التقنيات

| التقنية | الاستخدام |
| --- | --- |
| TanStack Start / React 19 | إطار التطبيق (SSR) والمسارات |
| TypeScript | اللغة الأساسية |
| Vite | أداة البناء |
| Tailwind CSS v4 | التنسيق والتصميم |
| Recharts | الرسوم البيانية |
| Leaflet + react-leaflet | الخريطة التفاعلية |

| @tanstack/react-query | إدارة البيانات من الخادم |

## هيكل المشروع

```
src/
├── components/
│   ├── accessibility/   # أداة الوصول
│   ├── reports/         # مكوّنات التقارير (القائمة/البطاقة/النموذج)
│   ├── site/            # التخطيط العام، الخريطة، بطاقات الإحصاء، الرسوم
│   ├── tts/             # القراءة الصوتية (ReadAloud)
│   └── ui/              # مكوّنات الواجهة
├── i18n/                # نظام الترجمة (ar.ts / en.ts / data.ts / index.ts)
├── lib/                 # الدوال والخدمات (reports.functions, use-auth, excel…)
├── data/                # كتالوج المؤشرات والبيانات النموذجية
├── integrations/supabase/
└── routes/              # مسارات الصفحات
```

## التشغيل محلياً

تتطلب Node.js و npm — [التحميل عبر nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/MuhnnadQatanani1/dashpord-PACC.git
cd dashpord-PACC
npm i
npm run dev
```

يفتح التطبيق على `http://localhost:3000`.

## نظام الترجمة

- `src/i18n/ar.ts` و `src/i18n/en.ts`: قواميس الواجهة (يجب أن تكون متكافئة المفاتيح).
- `src/i18n/data.ts`: ترجمة بيانات المحتوى العربي (كتالوج المؤشرات، الخريطة، التقارير).
- `useLocale()` يوفر: `t()` للواجهة، `d(ar)` لبيانات المحتوى، `pick(ar, en)`، و `locale/dir/isRtl`.
- اللغة الافتراضية هي العربية (RTL) ويتم تخزين الاختيار في `localStorage` بمفتاح `pacc-locale`.

## قاعدة البيانات

التطبيق يستخدم Supabase لتخزين التقارير والمصادقة في صفحة إدارة التقارير، مع وجود بيانات نموذجية (mock) كبديل تلقائي عند غياب الاتصال. مخطط الجدول موجود في:

```
supabase/migrations/20260816090000_create_reports_table.sql
```

## النشر

```sh
npx nitro deploy --prebuilt
```
